드론 조립과 정비 시뮬레이터

조작법 안내

🖱 화면 보기

  • 빈 곳 끌기: 시점 돌리기
  • 휠: 확대·축소
  • 빈 곳 더블클릭: 처음 시점으로
  • 가장 앞(바깥)에 있는 물체가 눌립니다. 가려진 부품은 시점을 돌리거나 위 부품을 떼고 누르세요.

🔧 부품 장착

  • 부품을 눌러 끌기: 장착할 자리 근처로 가져가면 노란 고리가 표시되고, 놓으면 붙습니다.
  • 작업대 빈 곳에 놓으면 내려놓습니다.
  • 부품 클릭: 정보창(돌리기·뒤집기·선 연결 등)

🔌 선 연결

  • 선 끝(커넥터)을 눌러 집고 → 꽂을 곳을 누르거나 끌어다 놓기
  • 선 끝이 작거나 가려지면 정보창의 선 연결 버튼
  • 선을 든 채 FC·하판·수신기를 누르면 세부 화면에서 자리를 고릅니다.
  • Esc: 들고 있는 선 놓기 · 연결된 선을 누르면 분리 메뉴

📋 진행

  • 위쪽 ‹ › 버튼: 하드웨어 설정 → 소프트웨어 설정 → 테스트
  • 소프트웨어 설정은 오른쪽 메뉴에서 차례대로
  • 작업대의 조종기를 누르면 조종기 화면
  • 마지막 단계에서 완료 → 종료를 누르면 기록이 관리자에게 전송됩니다.
