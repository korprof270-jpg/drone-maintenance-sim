# 드론 조립과 정비 시뮬레이터

교육용 3D 드론 조립·배선·설정·테스트 실습 프로그램입니다. 브라우저에서 바로 실행됩니다.

- 단계: 하드웨어 설정 → 소프트웨어 설정(미션 플래너 방식 메뉴) → 테스트
- 시작 화면에서 이름 입력 후 START, 마지막에 "종료"를 누르면 실습 기록이 관리자 구글 시트로 전송됩니다.

## 배포

`main` 브랜치에 올리면 GitHub Actions가 GitHub Pages로 배포합니다.
처음 한 번 저장소 **Settings → Pages → Source**를 **GitHub Actions**로 설정하세요.

## 관리자 기록

`docs/관리자-기록-구글시트.md`의 안내대로 Apps Script를 웹 앱으로 배포한 뒤,
그 주소를 `js/config.js`의 `recordUrl`에 넣으면 됩니다.

## 고장 진단 시험 (관리자 출제)

1. 주소 끝에 `?admin`을 붙여 엽니다: `https://korprof270-jpg.github.io/drone-maintenance-sim/?admin`
2. **관리자 · 고장 진단 시험 만들기**(또는 위쪽 **시험 만들기**)를 누르고, 낼 고장을 고릅니다. 교육생에게 보일 증상 문구는 고쳐 쓸 수 있습니다.
3. **시험 링크 만들기** → 링크를 복사해 교육생에게 보냅니다. 같은 링크는 모두 같은 고장(같은 위치)으로 열립니다.
4. 교육생은 링크로 열어 이름 입력 → START. 정상 조립·설정된 기체에 고장이 심어진 상태(배터리는 장착만 하고 커넥터는 뺀 상태)로 시작하고, 증상만 보고 원인을 찾아 고친 뒤 찾은 원인을 적습니다.
5. 종료하면 구글 시트 "상세" 탭에 증상별로 실제 원인, 교육생 답, 해결 여부가 기록됩니다. 이름 뒤에 "(고장 진단)"이 붙습니다.

## 그래픽

- 3D 엔진: three.js r170 (`vendor/three`, MIT). 인터넷 CDN 없이 저장소에 포함되어 있습니다.
- 실사 환경광: Poly Haven 작업장·하늘 HDRI (`assets/hdri`, CC0).
- 후처리: 주변광 차폐(GTAO), 빛 번짐(Bloom), ACES 톤매핑, 4× MSAA. 프레임이 느리면 후처리부터 자동으로 끕니다.

## 채점 (관리자만 봄)

- 100점에서 감점: 오류 −10, 주의 −3, 안전 위반 1회 −20 (전원 연결 중 배선·부품 작업 / 프로펠러를 단 채 모터 테스트, 같은 종류는 10초 안에 1회로 셈)
- 고장 진단 시험: 미해결 고장마다 100÷문제 수 감점 (+ 안전 위반)
- FC 소손(PMU 없이 배터리 전원)은 0점
- 70점 이상 합격. 교육생 화면에는 점수가 나오지 않고, 구글 시트 '기록' 탭의 '시동 전 점검' 칸(예: "85점 합격 · 시동 전 점검 통과")과 '상세' 탭의 '채점' 줄에 기록됩니다.
